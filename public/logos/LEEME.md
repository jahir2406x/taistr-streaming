# Carpeta de Marcadores de Logos (`public/logos/`)

Esta carpeta incluye marcadores SVG neutros (sin logotipos registrados ni material con derechos de autor) para cada plataforma:
- `netflix.svg`, `disney-plus.svg`, `hbo-max.svg`, `spotify.svg`, `prime-video.svg`, `apple-tv-plus.svg`, `vix.svg`, `paramount-plus.svg`, `crunchyroll.svg`

Si deseas usar tus propios iconos o imágenes en WebP/AVIF/SVG, reemplaza estos archivos manteniendo el mismo nombre (slug) del servicio.
