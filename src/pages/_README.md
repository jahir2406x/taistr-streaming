# Carpeta `src/pages/`
- **Qué hay aquí**: Rutas de la web (`/`, `/servicios/[slug]`, `/garantia`, `/privacidad`, `/404` y `/sitemap.xml`).
- **Si quiero cambiar el contenido de Garantía o Privacidad**: Ve a `src/editar/textos/garantia.md` o `src/editar/textos/privacidad.md`.
- **Si quiero agregar o editar un servicio**: Ve a `src/editar/servicios/` y `src/editar/servicios/orden.json`.
