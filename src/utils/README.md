# Carpeta `src/utils/`
- **Qué hay aquí**: Funciones auxiliares de formateo de enlaces de WhatsApp (`whatsapp.ts`) y lectura de documentos legales (`markdown.ts`).
- **Si quiero cambiar el número de WhatsApp o los mensajes**: Ve a `src/editar/marca.ts` y `src/editar/mensajes-whatsapp.json`.
- **Qué no tocar**: No pongas el número ni textos fijos aquí; se toman automáticamente de `src/editar/`.
