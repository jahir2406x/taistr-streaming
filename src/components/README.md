# Carpeta `src/components/`
- **Qué hay aquí**: Piezas visuales (encabezado, pie, tarjetas de servicio, secciones de inicio y `ui/BotonWhatsApp.astro`).
- **Si quiero cambiar textos o botones visibles**: Ve a `src/editar/textos/` (`inicio.json`, `pie.json`, `botones.json`).
- **Si quiero cambiar mensajes de WhatsApp**: Ve a `src/editar/mensajes-whatsapp.json` o `src/editar/servicios/*.json`.
- **Qué no tocar**: No escribas textos ni números fijos aquí; todo se lee desde `src/editar/`.
