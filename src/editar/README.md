# Carpeta `src/editar/` — Guía rápida

- **QUÉ ES ESTA CARPETA**: Aquí están todos los textos, precios, países, medios de pago y servicios editables de tu web.
- **QUÉ PUEDES CAMBIAR**: Los textos y números dentro de los archivos `.json`, `.md`, `.ts` y `.css`.
- **QUÉ NO TOCAR**: No borres comillas `""`, comas `,` ni llaves `{}` en los archivos `.json`. Si tienes dudas, ejecuta `npm run check:data`.
