# Fuente Única de Garantía y Renovación (`garantia.json`)
- **`garantia_corta`**: Frase compacta para tarjetas y catálogos.
- **`garantia_panel`**: Frase para el panel de compra. Acepta `{duracion}` (ej. "3 meses") y `{meses}` (ej. 3).
- **`renovacion_frase`**: Promesa base de renovación que aparece en el panel y en el FAQ general.
- **`renovacion_nota`**: Nota secundaria (editable, usa `CAMBIAR:` para condiciones propias de tu servicio).
- **`vigencia_etiqueta`**: Formato de vigencia para planes (usa `{duracion}`).
- Toda la web lee de este archivo para garantizar coherencia sin textos duplicados ni desactualizados.
