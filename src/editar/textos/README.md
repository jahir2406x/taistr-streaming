# Carpeta `src/editar/textos/`

- **QUÉ ES ESTA CARPETA**: Textos del inicio (`inicio.json`), pie (`pie.json`), botones (`botones.json`), panel de compra (`panel-compra.json`) y páginas legales (`garantia.md`, `privacidad.md`).
- **PANEL DE COMPRA (`panel-compra.json`)**: Edita aquí el saludo de confirmación, la frase de garantía, el tiempo de entrega (`CAMBIAR:`), los 3 pasos y los textos del botón apagado/encendido.
- **QUÉ PUEDES CAMBIAR**: Cualquier frase, título, paso o respuesta frecuente dentro de estos archivos (puedes usar `{marca}`).
- **QUÉ NO TOCAR**: En los archivos `.json` conserva los nombres de las claves; en los `.md` conserva los títulos que empiezan con `## `.
